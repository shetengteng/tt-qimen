## 一键生成脚本建议(待审核后再执行)

### 方案 A:Edge-TTS(免费 · 推荐 · 无需 API Key)

```bash
# 安装
pip install edge-tts

# 单段生成示例(以 SEG 01 为例)
edge-tts \
  --voice "zh-CN-YunyangNeural" \
  --rate "-5%" \
  --pitch "-2Hz" \
  --text "古人问天,今人问己。" \
  --write-media seg_01.mp3
```

### 方案 B:OpenAI TTS(质量更高 · 需要 OPENAI_API_KEY)

```bash
curl https://api.openai.com/v1/audio/speech \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "tts-1-hd",
    "voice": "onyx",
    "speed": 0.95,
    "input": "古人问天,今人问己。"
  }' \
  --output seg_01.mp3
```

### 拼接(8 段 mp3 + 静音 → 单一 voiceover.mp3)

```bash
# 生成 silence(根据每段空白时长调整)
ffmpeg -f lavfi -i anullsrc=r=44100:cl=mono -t 2.5 -q:a 9 -acodec libmp3lame sil_pre.mp3
# ... 各段间静音同理
ffmpeg -f concat -safe 0 -i concat.txt -c copy voiceover.mp3
```

`concat.txt`:
```
file 'sil_pre.mp3'
file 'seg_01.mp3'
file 'sil_s1_s2.mp3'
file 'seg_02.mp3'
... 依此类推
```

## ⚠️ 注意事项

1. **本文件不包含 mp3,只包含文案与生成方案**。用户 review 通过后再实际生成音频。
2. **时间码以 `script.md` 为唯一源头**,若 script 改时序,本文件需同步更新。
3. **配音总时长 ~65s,镜头总时长 85s**,余 20s 用于:开场前留白(2.5s)+ 段落间呼吸(每段 0.5-2s)+ 收尾余音(1.5s)。
4. **语速建议** Edge-TTS 用 `--rate "-5%"` 略慢,更稳重;OpenAI 用 `speed: 0.95`。
