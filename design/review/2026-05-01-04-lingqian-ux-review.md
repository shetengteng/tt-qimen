# 灵签页面 UI/UX 审查报告

| 项 | 值 |
|---|---|
| 评估日期 | 2026-05-01 |
| 评审对象 | `/lingqian` 路由(国风 + 简约 双主题) |
| 测试视口 | 1440×900 / 390×844 |
| 测试用例 | 第 79 签(暗扶倒铜旗)overall 主题 |
| 截图存档 | `.cursor/ux-review-2026-05-01/lingqian-*.png` |
| 综合评价 | **A- / 8.0 分** |

> 灵签是产品**最有沉浸感**的模块。签筒摇签动效 + 签号 + 4 行诗 + 解曰 + 仙机 + 分事而问,**仪式感 - 数据 - 实用**三层皆备。本次反馈最关键修复(诗 4 行水平堆叠)已生效。仍有少量提升空间。

---

## 一、最高优先级问题(P0)

### P0-1 · 桌面端 1440 签筒图过大,占据视口主导地位

**证据**:`lingqian-guofeng-1440.png` 签筒图占据了**首屏垂直高度的 ~40%**(约 350px 高),却没有传达任何与 79 签相关的信息(签筒只是装饰)。

**问题**:用户从 deeplink 进入,首屏看到的是「巨大的签筒装饰图」+「问题输入框」,而真正的结果(79 签内容)需要再向下滚 1 屏。

**修复建议**:
- 当 `result.value` 已有值(deeplink 模式),把签筒缩小为 ~120px 角标置于结果卡左上
- 或者把签筒移到结果区作为「来源标识」,首屏直接显示签号 + 4 行诗

### P0-2 · 移动端「分事而问 / 六事开示」按钮太小

**证据**:`lingqian-guofeng-390.png` 底部「家宅 / 婚姻 / 求事 / 财运 / 出行 / 健康」6 个圆形 chip 按钮,每个估算 ~36×36px,**未达 44×44 a11y 标准**。

**修复建议**:`min-width: 44px; min-height: 44px; padding: 10px 16px;`,改 pill 形状横向排列。

---

## 二、高优先级问题(P1)

### P1-1 · 1440 桌面端「典故」段落字号偏小,与正文同号但段落极长

**证据**:`lingqian-minimal-1440.png` 中典故 paragraph(「暗扶倒铜旗(隋朝唐传)…」)是单段长文,~10 行,缺少 break。

**修复建议**:
- 把典故按「时代 / 人物 / 寓意」分段
- 或加可折叠 `<details>` 让用户主动展开

### P1-2 · 「解曰」与「仙机」双卡布局在桌面端显得弱

**证据**:1440 视口下「解曰」「仙机」并排,但内容只有 ~80 字,占用 50% 宽,**视觉空虚**。

**修复建议**:
- 桌面端把「解曰」「仙机」「分事而问」并列三栏 grid
- 移动端继续单列堆叠

### P1-3 · 签号「79」与「暗扶倒铜旗」标题层级不清

**证据**:`lingqian-minimal-1440.png` 「79」是大数字,「暗扶倒铜旗」是右上角的标签 + 「中平」吉凶。

**问题**:对应关系不直观,新手不知道「中平」是吉凶。

**修复建议**:
- 改成左上「第 79 签 · 暗扶倒铜旗」一行 title
- 右上「中平」用色块强调(吉=红、平=黄、凶=灰)
- 加 hover tooltip:「中平 = 顺则可成,逆则需止」

### P1-4 · 输入框 placeholder「如:升学考试、姻缘、事业、求职…」很好,但不可清空

**证据**:输入「蛇」之类的关键字后,无 clear icon。

**修复建议**:加「×」清空按钮(常见模式),或 esc 键支持。

### P1-5 · 签筒摇签动效在 deeplink 进入时仍触发了一瞬

**证据**:观察到进入页面有 ~0.5s 的「签筒摇晃」过场,即使是 deeplink 直达签号。

**修复建议**:`onMounted` 检测到 `route.query.id` 时,跳过摇签动画,直接 `centerpieceStage = 'hidden'`(代码中已有 `'hidden'` 状态,只需提前设置即可)。

## 三、中优先级问题(P2)

| ID | 问题 | 建议 |
|---|---|---|
| P2-1 | 占问主题 select(综合/学业/事业/婚姻…)选中态不突出 | 加底部 underline 或加粗 |
| P2-2 | 「再签」按钮位置在表单内,出现「再签」会让人疑惑「是不是我的问题打错了?」 | 改文案「再求一签」,移到结果卡底部 |
| P2-3 | 4 行诗居中堆叠时,行间距 ~12px,稍紧 | `line-height: 2.0` 加大呼吸感 |
| P2-4 | 缺少「收藏 / 历史签」入口 | 在标题区加一个 ❤ 图标 |
| P2-5 | guofeng 签筒图是 PNG 透明底,minimal 主题下背景已变浅,签筒底色仍然是黄色 | 提供 SVG 多色版本 |

## 四、低优先级 / 增强(P3)

1. 100 签数据可加入「求得此签者占比」「最近 24h 内被求次数」等社交反馈
2. 「立即分享」CTA 在结果加载完成 ~3 秒后才出现,可加引导箭头
3. 国风主题字体「Songti / Kaiti」如未安装,fallback 字体观感差异大
4. 缺少「已知签号」直达入口(「我想看第 33 签」),用户必须摇签
5. AI 解读按钮(「问 AI」)是按钮,但点击后行为未在截图中展示,需要确认是否打开侧栏

| **吉凶分级 chip** | 「中平」简洁直观 |
| **分事而问** | 6 事维度提供具体应用建议,实用性强 |
| **TopicTabs** | 切换占问主题(学业/事业…)即时反馈 |
