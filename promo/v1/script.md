# tt-qimen 宣传片 · 总分镜脚本

**版本** v1.0 · 草稿待 review
**总时长** 85 秒(目标 60-90 秒区间,留 5 秒缓冲)
**用途** 产品主页 hero 视频 / 社交媒体宣发 / Release 发布
**风格** 国风沉稳 + 现代克制,7 分文化 + 3 分科技
**画幅** 1920×1080 (16:9),60 fps 推荐
**色谱** 朱砂红 `#C23A2A` · 宣纸黄 `#FFFBF0` · 墨黑 `#1A1613` · 深紫 `#3B2F63`(用于"简约主题"过场)
**字体** 标题/卯酉字 `STZhongsong / Noto Serif CJK SC`,正文 `PingFang SC / Inter`

## 下一步建议(待用户决定)

1. **review 本脚本**,调整文案口径(尤其是 S1/S7/S9 的关键句)
2. 确认后选择配音方案:
   - **方案 A** OpenAI `tts-1-hd`(中文音色 `onyx`/`alloy`,自然但略带轻微洋音)
   - **方案 B** 阶跃星辰 / 字节豆包 TTS(纯正中文播音腔,需中国大陆 API)
   - **方案 C** macOS 原生 `say -v Tingting`(完全免费,机械感稍强)
   - **方案 D** Edge-TTS `zh-CN-YunyangNeural`(免费、播音腔、推荐)
3. 选定后由 AI 一次性生成 `voiceover.mp3`(8 段拼接 + 静音衔接)
4. 最终合成:`ffmpeg` 录屏 `storyboard.html` + 烧录 srt + 叠加 mp3 → `tt-qimen-promo.mp4`
