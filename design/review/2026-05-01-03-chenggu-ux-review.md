# 称骨页面 UI/UX 审查报告

| 项 | 值 |
|---|---|
| 评估日期 | 2026-05-01 |
| 评审对象 | `/chenggu` 路由(国风 + 简约 双主题) |
| 测试视口 | 1440×900 / 390×844 |
| 测试用例 | 1990-06-15 09-11(巳时) 男 公历 |
| 截图存档 | `.cursor/ux-review-2026-05-01/chenggu-*.png` |

> **6 模块中 UX 完成度最高**。「3.8 两 / 三两八钱」核心结果一目了然,左右双卡布局(BirthForm + 秤天平)富有仪式感,4 句歌诀正确居中,歌诀释义层次分明。仅有少量优化空间。

---

## 一、最高优先级问题(P0)

### P0-1 · 移动端「称骨中」骨架屏 modal 锁屏(同八字 P0-2)

**证据**:`chenggu-guofeng-390.png` / `chenggu-minimal-390.png` 都被「称骨中」全屏 modal 占据。

**修复**:同八字方案 — inline skeleton + 减短延迟。
**影响范围**:`useSkeletonReveal` 是公共 composable,**修一处,8 字 / 紫微 / 称骨 三个模块通受益**(实际 P0)。

### P0-2 · 1440 桌面端整体内容只占 ~50% 宽

**证据**:`chenggu-guofeng-1440.png`、`chenggu-minimal-1440.png` 全页截图,内容居中,左右各有 ~250-300px 留白。

**根因**:`themes/{guofeng,minimal}/components/chenggu.css` `max-width: 1080px` 之类约束 + 内部子卡片再次 `max-width`。

**修复建议**:
- 把整体 max-width 提到 `min(94vw, 1280px)`
- 把「秤」展示卡放大,加入秤砣摆动微动画(已经是核心吸引点,放大有惊喜感)

---

## 二、高优先级问题(P1)

### P1-1 · 「3.8 两」结果卡视觉权重不够

**证据**:`chenggu-minimal-1440.png` 右上角的「3.8 两」字体只有 ~32px,**和左侧 BirthForm 视觉权重相当**。这是页面**最关键**的输出,应该有更强存在感。

**修复建议**:
- 字号从 ~32px → 48-64px(配合天平图标)
- 加渐变 / 描边 / 衬线,使其成为视觉锚点
- 国风主题增加 ◆ 朱印 装饰已有

### P1-2 · 4 张「年骨/月骨/日骨/时骨」卡片信息密度低

**证据**:每个卡片只有「0.9 两」+ 一行小字,占了 1/4 页宽,空间利用低。

**修复建议**:
- 4 卡合并为一行 inline chip,节省垂直空间
- 或在每张卡里加更多信息:对应干支、典故出处

### P1-3 · 歌诀释义卡仅 1 段文字,缺少「关键句高亮」

**证据**:歌诀「一生骨数属中流 / 劳碌奔波何日休 / 若问中年衣食禄 / 蛛丝虽细未断头」+ 释义「骨重居中偏下,一生辛苦不歇,『蛛丝未断头』是关键……」

**问题**:释义里的「关键句」「典故来源」「现代解读」可以分层呈现。

**修复建议**:用结构化卡片:
- 字面 → 隐喻 → 现代关照 三段式
- 把歌诀里的关键 token(如「蛛丝未断头」)在释义中加 `<mark>` 高亮

### P1-4 · `◆` 装饰符与 P0 通用问题相同

`◆ 歌诀释义` 用 SVG 替代。

## 三、中优先级问题(P2)

| ID | 问题 | 建议 |
|---|---|---|
| P2-1 | 「下一骨」按钮位置不显眼 | 移到结果卡内,或浮起 sticky |
| P2-2 | 缺少「分享单张歌诀」预览 | 类似紫微 share card 模式 |
| P2-3 | 「巳时(9-11)」select option 的时辰范围用括号,可改更直观图标 | `🌅 巳时 9-11` 之类(注意先问用户是否用 emoji) |
| P2-4 | 未提供「重新选生辰」快捷按钮(只能滚动到顶部 form) | 加 sticky bottom CTA |
| P2-5 | 性别选项「男 / 女」未交代影响 | 加小字提示「不同性别歌诀略异」 |

---

## 四、低优先级 / 增强(P3)

1. 「四骨称重」`年 / 月 / 日 / 时` 与「天平图」之间缺少视觉关联线
2. 国风主题字体「Kaiti SC / Kaiti」依赖系统字体,Windows 用户可能 fallback 到普通字体,失去韵味 — 考虑 webfont 兜底
3. 缺少「不同骨数对应级别」科普(2 两 = 较弱 / 4 两 = 中流 / 7 两 = 命旺),用户不知道 3.8 两好不好
4. 桌面端可加「与名人骨重对比」彩蛋(如曾国藩 6.7 两、毛泽东 5.6 两)
