> 黄历是 6 模块中**信息密度最高、实用价值最强**的模块。今日 / 宜 / 忌 / 9 事速查 / 月历五段集成完整,与传统纸质黄历的呈现习惯高度契合。仅有少量响应式与可发现性问题。

## 一、最高优先级问题(P0)

### P0-1 · 1440 桌面端整体内容只占 ~42% 屏宽,严重浪费

**证据**:`huangli-guofeng-1440.png` / `huangli-minimal-1440.png` 全页截图,内容居中,左右各有 ~280-320px 留白。

**根因**:外层 `.gf-container` `max-width: ~960-1080px`,加上内部子卡再设 `max-width`。

**修复建议**:
- 整体框架 `width: min(94vw, 1280px)`
- 桌面端可用「左 sticky 选日器 + 右 main(今日 / 宜忌 / 月历)」双栏 (≥1024px 启用)

### P0-2 · 「危」字标签的字面含义对新手不友好

**证据**:`huangli-minimal-1440.png` 右侧大字「危」**单字呈现**,在 12 建星(建/除/满/平/定/执/破/危/成/收/开/闭)体系下指「凶险防灾」。

**问题**:用户不熟悉 12 建星,看到「危」单字会困惑(是危险还是危房?)。

**修复建议**:
- 「危」字下加小字「12 建星 - 防险」
- 加 hover tooltip:「危日宜守不宜攻,适合避凶」
- 或者用色彩编码(危=暗红,定=绿,等)

## 二、高优先级问题(P1)

### P1-1 · 「9 事速查」9 个事由图标含义不直观

**证据**:`huangli-guofeng-1440.png` 「9 事速查」9 个 emoji 风格图标:祭祀 ❤ 出行 ✈ 动土 ⚡ 开市 📜 签约 🪒 入宅 🏠 祈福 ☯ 破土 ⬛

**问题**:
- 图标风格不统一(emoji + 几何符号混用)
- 部分图标语义模糊(祭祀的图标用了 ❤?)
- 每个图标下「忌」「宜」标签字号小

**修复建议**:
- 全部换 SVG (lucide / 自定义)
- 每个事由 box 加色块边框(宜=绿、忌=红)
- 大屏可考虑改为「2 列 × 9 行」表格,信息密度提升

### P1-2 · 月历卡(2026 年 5 月)红色「1」当日标记 + 旁边数字未说明

**证据**:`huangli-minimal-1440.png` 月历每个日期下有「五一 / 立夏 / ●」等小字。

**问题**:
- 红点 `●` 含义不明(节气?宜忌?)
- 「五一」「立夏」是节假日 + 节气混杂

**修复建议**:
- 月历下加 legend「● 黄道日 / ● 黑道日」(已有 `黄道吉 黑道凶` 字样,但太小)
- 节假日用🎯 ,节气用 🌸,区分

### P1-3 · 「宜 / 忌」事由 chip 信息密度低

**证据**:「宜:沐浴 / 嫁娶 / 安门 / 修饰 / 起基」「忌:祭祀 / 福德 / 入定 / 牢狱 / 害宫」

**问题**:每个 chip 只有事由名,没有「为什么宜 / 忌」「具体怎么做」的解释。

**修复建议**:每个 chip 可点击 → 展开详细说明(包括传统出处)。

### P1-4 · 「冲煞 / 干支 / 五行」等术语堆叠,缺少分组

**证据**:`huangli-guofeng-1440.png` 今日卡片左下角有「丙午年 / 王巳月 / 乙未日」+ 「胎神 -- ?」+ 「冲(辛巳) - 兔煞」+ 「岁煞 / 紫白星」等大量术语。

**问题**:对非传统命理用户,这些信息**视觉权重相当**,无优先级。

**修复建议**:
- 用 `<dl>` 分组(干支 / 神煞 / 节气 / 物候)
- 或加「专家模式」开关,默认隐藏深度术语

### P1-5 · 「下一日 / 上一日」之类导航缺失

**证据**:用户看完今日,想看明日,只能改日期 select。

**修复建议**:今日卡两侧加「← 昨日 / 明日 →」浮动按钮。

## 三、中优先级问题(P2)

| ID | 问题 | 建议 |
|---|---|---|
| P2-1 | 「日 - 农历(Y M D)」对应关系太小 | 加大对照字号 |
| P2-2 | 没有「按事由倒查日期」功能 | 加「最近适合嫁娶的日子」搜索 |
| P2-3 | 月历卡导航(4 月 / 5 月 / 6 月)按钮触摸目标小 | min-width: 44px |
| P2-4 | 缺少「保存为日历事件」(.ics 导出) | 加 CTA |
| P2-5 | 移动端今日卡的「危」字 + 干支 + 神煞挤在一屏内,字号小 | 移动端拆 2 段 |
| P2-6 | 缺少「历史今日 / 节令小知识」 | 加引擎丰富内容 |
| P2-7 | 「今日」按钮和「查询」并列,但默认值就是今日,「今日」按钮反而无作用 | 仅在 date != today 时显示 |

## 四、低优先级 / 增强(P3)

1. 国风主题「危」字字体可加篆书 / 隶书风格,提升仪式感
2. 缺少「分享今日黄历」(二维码 / 微信分享)
3. 桌面端可加「迷你年历」(全年 12 月缩略)
4. 缺少「农历节日提醒」(春节、端午等关键节日)
5. AI 解读按钮(「问 AI」)可定位到「请解释今日宜 / 忌」prompt
6. 月历卡「黄道 / 黑道」筛选 toggle(只看黄道日)
