## 一键生成脚本(待 review 后再执行)

### 方案 A:Edge-TTS(免费 · 推荐 · 无需 API Key)

```bash
pip install edge-tts

# 主音色生成 SEG 00-09, 11, 12
edge-tts \
  --voice "zh-CN-YunyangNeural" \
  --rate "-5%" \
  --text "段落文案" \
  --write-media seg_dev_NN.mp3

# 体育播报员音色生成 SEG 10 (技术栈墙)
edge-tts \
  --voice "zh-CN-YunjianNeural" \
  --rate "+0%" \
  --text "技术栈:Vue 3、Vite 5、TypeScript 严格模式..." \
  --write-media seg_dev_10.mp3
```

### 方案 B:OpenAI TTS

```bash
curl https://api.openai.com/v1/audio/speech \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "tts-1-hd",
    "voice": "onyx",
    "speed": 0.97,
    "input": "段落文案"
  }' \
  --output seg_dev_NN.mp3
```

### 拼接(13 段 mp3 + 静音 → voiceover-dev.mp3)

```bash
ffmpeg -f lavfi -i anullsrc=r=44100:cl=mono -t 2.0 -q:a 9 -acodec libmp3lame sil_pre.mp3
ffmpeg -f concat -safe 0 -i concat-dev.txt -c copy voiceover-dev.mp3
```
