# 姓名学(五格剖象)页面 UI/UX 审查报告

| 项 | 值 |
|---|---|
| 评估日期 | 2026-05-01 |
| 评审对象 | `/xingming` 路由(国风 + 简约 双主题) |
| 测试视口 | 1440×900 / 390×844 |
| 测试用例 | 张三丰 男 1990 |
| 截图存档 | `.cursor/ux-review-2026-05-01/xingming-*.png` |
| 综合评价 | **A- / 8.0 分** |

> 姓名学模块**信息架构清晰**:笔画分解 → 五格(天/人/地/外/总)→ 三才配置 → 整体评分。68 分仪表盘是亮点。但 1440 桌面端**整体宽度利用低**(约 50%),五格的「关系连线」缺失是核心可改进点。

---

## 一、最高优先级问题(P0)

### P0-1 · 1440 桌面端内容区只占 ~50% 宽,大量留白浪费

**证据**:`xingming-guofeng-1440.png` / `xingming-minimal-1440.png` 全页截图,内容左右各有 ~250-280px 留白。

**根因**:`NameInput`、`StrokesBreakdown`、`FiveGrids` 等组件都设了 `max-width: ~720-960px`。

**修复建议**:整体框架 `width: min(94vw, 1280px)`,五格 `FiveGrids` 内的 5 个数字卡可以更舒展(目前 12 / 19 / 14 / 21 / 32 都在 ~70px 方框内,大屏可放到 100-120px)。

### P0-2 · 五格的 5 个数字之间缺少「关系连线 / 公式说明」

**证据**:`xingming-minimal-1440.png` 五格布局:
```
12 天 ......... 19 人
       14
21 地 ......... 32 总
```

**问题**:**五格之间是有计算关系的**(天 + 人 - 1 = 总?人 = 姓最末 + 名第一?),但 UI 没有任何视觉提示。新手看到 5 个数字,不知道这是什么、为什么是这些值。

**修复建议**:
- 加 SVG 连线 + 公式标注,如「天格(姓笔画)= 12」「人格(姓末 + 名首)= 14」
- 或加可折叠「五格计算说明」段
- 鼠标 hover 数字时高亮对应的笔画来源(右侧已有「张 / 三 / 丰」笔画显示,可联动)

## 二、高优先级问题(P1)

### P1-1 · 「68 分」整体评分仪表盘视觉权重最强,但位置在最下方

**证据**:`xingming-guofeng-1440.png` 「68 分」仪表盘是页面最大、最有色彩的元素,但出现在第 4 屏底部,**用户必须滚到底才能看到分数**。

**问题**:违反「核心信息优先」。如果用户只想知道「这名字好不好」,要等很久。

**修复建议**:
- 在结果区顶部加一个 sticky 「评分摘要 banner」(68 分 + 一句话评语),滚动时常驻
- 或者用类似紫微的 ResultBanner 模式,把 68 分放在顶部

### P1-2 · 五格旁边的 5 段文字解读视觉关系不清

**证据**:`xingming-minimal-1440.png` 中,左侧是五格数字方框,右侧是 5 段解读(「天格 12 画 - 木」「人格 14 画 - 火」...)。

**问题**:数字方框与右侧解读**没有视觉连线 / hover 联动**,用户要靠数字记忆来对应。

**修复建议**:
- 数字方框 hover → 右侧对应段落高亮 + 滚动定位
- 或者把每段解读移到对应数字方框正下方(yueyu 布局优先)

### P1-3 · 「三才配置」连线方向不明确

**证据**:`三才配置` 段「木 → 火 → 木」(天 / 人 / 地),用 → 箭头连接。

**问题**:箭头方向暗示因果,但三才是**并列关系**(天人地三方)。

**修复建议**:用空心圆 + 横线连接,或用「上下中」纵向布局,贴近传统三才图。

### P1-4 · 输入框「姓 / 名 / 性别 / 生年」分布式但未提示规则

**证据**:`NameInput` 4 个字段并列,但没有提示:
- 姓 / 名 各 ≤2 字(代码里有 slice(0, 2))
- 性别 / 生年 是否必填

**修复建议**:
- 字段下加小字「最多 2 字」「可选」「为空则不计大运」
- 错误时即时校验红框

### P1-5 · 「五格剖象结果」标题旁的 3 个小标签(天人地外总 / 81 数理 / 阴阳学)信息过密

**证据**:标题下副标题「天人地外总 · 81 数理 · 阴阳学」,**全是术语**,新手看不懂。

**修复建议**:换成「评估你姓名的吉凶能量与数理寓意」之类的人话。

## 三、中优先级问题(P2)

| ID | 问题 | 建议 |
|---|---|---|
| P2-1 | 「张 / 三 / 丰」笔画卡片只显示笔画数,没显示部首 / 五行 | 加部首 + 五行小字 |
| P2-2 | 缺少「换名建议」入口 | 加 CTA「想换更好的字?试试这些」 |
| P2-3 | 仪表盘 68 分的颜色编码(60-69 = 黄?70-79 = 绿?)无 legend | 加颜色梯度图例 |
| P2-4 | 「重新起名」按钮位置不明显 | 浮起 sticky |
| P2-5 | 缺少「人名重名查询」之类的延伸功能 | 后续版本 |
| P2-6 | guofeng 主题「人格 14」红色卡片在 minimal 主题变成紫色,色彩语义不一致 | 统一吉凶色 token |

## 四、低优先级 / 增强(P3)

1. 「81 数理」详解可加点击展开,而非全文罗列
2. 笔画来源采用「康熙字典」还是「现代标准」未说明,影响计算结果
3. 缺少「同名名人」分享(轻社交功能)
4. 性别影响计算(如外格变化)未明确说明
5. 国风主题「张三丰」三个字字体偏淡,可加书法描边

---

## 五、做得好的地方

| 维度 | 表现 |
|---|---|
| **信息架构** | 笔画 → 五格 → 三才 → 评分 四步逻辑清晰 |
| **68 分仪表盘** | 半圆仪表 + 颜色梯度,直观且现代 |
| **5 个五格的色块编码** | 红/橙/紫/灰/绿对应吉/平/凶,色彩有意 |
| **三才配置图** | 木 → 火 → 木,五行流转可视化 |
| **5 段解读** | 内容详尽,典故 + 现代解读结合 |
| **响应式表现** | 移动端单列堆叠 OK,五格变 2×2+1 布局合理 |
