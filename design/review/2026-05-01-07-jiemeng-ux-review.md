# 解梦(周公解梦)页面 UI/UX 审查报告

| 项 | 值 |
|---|---|
| 评估日期 | 2026-05-01 |
| 评审对象 | `/jiemeng` 路由(国风 + 简约 双主题) |
| 测试视口 | 1440×900 / 390×844 |
| 测试用例 | 搜索关键词「蛇」 |
| 截图存档 | `.cursor/ux-review-2026-05-01/jiemeng-*.png` |
| 综合评价 | **A / 8.5 分** |

> 解梦模块是 6 模块中**结构最干净、最现代**的工具型页面。搜索 + 8 大类网格 + 卡片列表的经典 IA(信息架构),无需骨架屏 modal,响应式表现良好。仅有少量优化点。

---

## 一、最高优先级问题(P0)

### P0-1 · 1440 桌面端整体内容只占 ~50% 屏宽,卡片列表纵向极长

**证据**:`jiemeng-guofeng-1440.png` 全页截图,12 张「梦见蛇」结果卡纵向堆叠,**每张卡只占 50% 宽**,搜索体验类似手机版而非桌面版。

**根因**:`themes/{guofeng,minimal}/components/jiemeng.css` 强制单列。

**修复建议**:
- 桌面端结果卡 grid `repeat(auto-fill, minmax(380px, 1fr))`,2-3 列堆叠
- 8 大类网格在桌面端可改为 2 行 × 4 列(目前是 4 列 × 2 行 OK)

### P0-2 · 「梦见 X」结果卡缺少「占据(占吉/占凶)+ 现代心理」结构化标签

**证据**:每张结果卡内有「占据:?」「现代:?」两段说明,但没有结构化呈现:
- 占据 = 古典占断
- 现代 = 现代心理

**问题**:用户难以快速判断哪些是「古占」哪些是「心理」,导致信息密度高但识别效率低。

**修复建议**:
- 每张卡用左右分栏:`[占] 古典占断 / [心] 现代心理`
- 或加色块前缀:🟡 占 / 🟢 心理

## 二、高优先级问题(P1)

### P1-1 · 8 大类网格图标重复使用基本几何符(◯ ◇ □)

**证据**:`jiemeng-guofeng-1440.png` 8 类:
- 动物 ◯
- 人物 ∞ 
- 自然 ☰
- 身体 (碗形)
- 生活 ☰
- 神鬼 ✦
- 建筑 ☵
- 其他 (小)

**问题**:图标含义不直观,需要读文字才能识别。

**修复建议**:换 lucide / 自定义 SVG:
- 动物 🐾(可换 SVG)
- 人物 👤
- 自然 🌳
- 身体 ✋
- 生活 🏠
- 神鬼 👻
- 建筑 🏛
- 其他 ⋯

### P1-2 · 12 条结果卡都展开,信息过载

**证据**:搜索「蛇」共 12 条结果,从「梦见蛇咬自己」到「梦见蛇入井」全展开,**纵向滚动 6+ 屏**。

**修复建议**:
- 结果卡默认折叠正文,只显示标题 + 标签
- 点击「查看详情 →」展开
- 桌面端 hover 显示预览

### P1-3 · 标签(占吉 / 占凶 / 体内征兆 / 神示)颜色编码不一致

**证据**:`jiemeng-guofeng-1440.png` 中「白色」「金色」「红色」标签混用,语义不明。

**修复建议**:
- 占吉 = 绿
- 占凶 = 红
- 占平 = 灰
- 体内征兆 = 紫
- 神示 = 金

### P1-4 · 搜索框 + 「查询解梦 / 清空」按钮区在桌面端排版略空

**证据**:输入框 + 单选「自动识别」+ 2 按钮,占 1 行宽度,但只用了 ~50% 视觉权重。

**修复建议**:可加「热门关键词 chip」(梦见蛇 / 梦见水 / 梦见死人 / 梦见考试)在搜索框下方,提升发现性。

### P1-5 · 「查看详情」按钮无视觉反馈差异(hover / active)

**证据**:每张卡末「查看详情 →」按钮,没看到 hover 高亮(可能 CSS 未实现)。

**修复建议**:统一按钮 hover 状态。

## 三、中优先级问题(P2)

| ID | 问题 | 建议 |
|---|---|---|
| P2-1 | 缺少「最近查询历史」 | 已有 `RecentSearches` 组件但未在桌面端显眼位置 |
| P2-2 | 缺少「相关梦境推荐」 | 列表底部加「你可能也想了解」 |
| P2-3 | 没有「分享单条解梦」CTA | 加 share button 到结果卡 |
| P2-4 | 搜索 q 与 category 同时存在时,关系不明 | 加「在『动物』分类内搜『蛇』」面包屑 |
| P2-5 | 「自动识别」select 只有一个选项,意义不大 | 加「精确匹配」「模糊搜索」「相关推荐」三档 |
| P2-6 | 结果数(共 12 条)未显示 | 标题区加「12 条结果」 |

## 四、低优先级 / 增强(P3)

1. 缺少「我的梦境记录」(用户保存自己的解梦)
2. 可加 AI 助手「描述你的梦境,我帮你解读」入口
3. 移动端「按类浏览」+ 「搜索结果」共存,信息密度高
4. 国风主题「周公解梦」标题字体可加书法描边
5. 缺少「不同典籍解读对比」(《周公解梦》vs《敦煌本梦书》vs 现代心理学)

---

## 五、做得好的地方

| 维度 | 表现 |
|---|---|
| **干净的搜索 IA** | 输入框 + 8 大类 + 结果列表,经典且不臃肿 |
| **无骨架屏遮挡** | 数据加载快,无需 modal,**优于其他 5 模块** |
| **占据 + 现代** | 古今结合的内容策略,有差异化价值 |
| **响应式表现** | 移动端 8 类网格变 2×4,流畅 |
| **i18n 完整** | 所有标题 / 标签 / 占据词都正确翻译 |
| **结果数据丰富** | 一个「蛇」字下 12 条具体场景,内容厚度足 |
